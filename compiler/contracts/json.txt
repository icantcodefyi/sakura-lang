# The JSON contract (design §17.232 (b)): one line per `kind schema_version field type required|optional`.
# Append-only; `sakura_cli/tests/json_contracts.rs` checks every `--json` record against it. A field
# path is `a`, `a.b` for an object's field and `a[]` for an array's elements; an object or array
# without listed children is open (its keys or elements are not part of the contract). Types:
# string, integer, number, boolean, null, object, array, joined with `|`. Text fields (`message`,
# `title`, `render`) are `string` only: their wording is not part of the contract.
# `baseline 0.2.0`: the history of this file is append-only from the release named here (design
# §17.257 (1)); the one reset it records is spent.
