# Sakura cookbook

Generated by `cargo run -p agent_docs` from `compiler/examples/`. Edit the example files, then regenerate.

Small Sakura projects, each solving one everyday task: decoding JSON, reading a file,
calling an HTTP API, querying SQLite, serving a route or running an LLM agent. Each one is a
whole project with tests that run offline, so you can copy it, run it and change it.

Every recipe page shows the complete project: the source with its tests, the `sakura.toml`
manifest (the package name and its permissions, which list the files, network hosts and
environment variables the program may use) and any data or recorded fixture files.

## How the recipes are checked

Every project runs offline in the repository's tests (`cargo test -p sakura_cli --test examples`),
against the compiler in the same checkout, on the JavaScript backend. A recipe that talks to an
HTTP API or a model replays a *cassette* in its tests: a committed file of recorded requests and
responses. These cassettes are synthetic, so no network access or API key is needed. Running a
project needs Node 26, whose built-in SQLite the SQLite recipe uses.

To adapt a recipe, build the CLI from the same checkout and run `sakura --version` and
`sakura prompt` first. Sakura Lang is pre-1.0: read STABILITY.md before depending on an API.
The initial API baseline is compiler revision
[5cae349516c21714d90d36e87f1cfd6debe980c6](https://github.com/icantcodefyi/sakuralang/commit/5cae349516c21714d90d36e87f1cfd6debe980c6).
An installed skill's frontmatter records its compiler version and build revision. These
teaching examples are separate from the agent evaluation tasks.

Each page is generated from its example's `recipe.md`, `sakura.toml`, `src/main.sak` and
fixture files. Edit those sources, not the rendered pages, then run `cargo run -p agent_docs`
from `compiler/` to regenerate the cookbook and the skill reference.

## For agents

Finish only when no holes remain, independent tests pass, the requested target
builds, and contracts/tests/permissions have not been weakened. Repeat the frozen
baseline check after the final edits. Report missing prerequisites and failing
checks explicitly; do not claim a skipped test passed.

## Audit and verify

`sakura audit --json` inventories trust boundaries; it is not certification.
`sakura verify --json` requires the pinned solver and reports each obligation.
Exit 0 can include `unknown` or `unsupported`; inspect statuses and
`path_feasible`, including `W7002` for vacuity. A proof is conditional on its
recorded assumptions and target profile, not a whole-program guarantee.

### HTTP bodies, redirects and multi-turn tests

A body is a `Payload` (`import std/request.{Payload}`): build `Payload.Text(s)`,
`Payload.Bytes(b)` or `Payload.Empty` (`body: Payload.Text("s")` or
`.with_payload(…)`), and read it with a `match` or an accessor that takes a byte limit:
`Response.text(r, limit)` (an `Untrusted<String>`), `Response.json(r, limit)`,
`Response.bytes(r, limit)`, and the same three on `Request`. Redirects are followed by
default; `Redirect.Manual` returns the 3xx. `Http.sequence` answers each entry once, in
order, for a multi-turn exchange; `Http.scripted` keeps answering its first match.

```sakura test id=since-http
import std/http.{Http, Path}
import std/request.{Get, Payload, Redirect, Request}
import std/response.{HttpError, Response}
import std/url.{Url}

fn body_text(r: Response) -> String {
  match r.body {
    Payload.Text(s) => s,
    Payload.Bytes(b) => "{Bytes.len(b)} bytes",
    Payload.Empty => "",
  }
}

fn poll(url: String) -> String ! {Http, Fail<HttpError>} {
  body_text(Http.send(Request.of(Get, Url.from(url))))
}

test "each turn answers once, in order" {
  let turns = [
    (Path("/job"), Response.status(202, "pending")),
    (Path("/job"), Response.status(200, "done")),
  ]
  with Http.sequence(turns) {
    expect_eq(try { poll("https://api.example/job") }, Ok("pending"))
    expect_eq(try { poll("https://api.example/job") }, Ok("done"))
    expect(Result.is_err(try { poll("https://api.example/job") }))
  }
}

test "Redirect.Manual returns the 3xx itself" {
  let moved = Response { ..Response.status(302, ""), headers: [("location", "/new")] }
  with Http.sequence([(Path("/old"), moved)]) {
    let req = Request.of(Get, Url.from("https://api.example/old"))
    let got = try { Http.send(Request { ..req, redirect: Redirect.Manual }) }
    expect_eq(got.map(fn(r) { r.status == 302 }), Ok(true))
  }
}

test "a body is read under a byte limit" {
  let r = Response { ..Response.status(200, ""), body: Payload.Bytes(String.to_bytes("hi")) }
  expect_eq(try { Response.bytes(r, 1024) }, Ok(String.to_bytes("hi")))
  expect(Result.is_err(try { Response.bytes(r, 1) }))
}
```

### Console and Log

A user `handler Console` implements `print`, `read_line` and `eprint` (standard error).
`Log` fields render as compact JSON: `hits=3`, `id="x"`.

```sakura test id=since-console
fn tagged() -> Handler<Console, {Console}> {
  handler Console {
    fn print(line) { Console.print("out: {line}") }
    fn eprint(line) { Console.print("err: {line}") }
    fn read_line() { Console.read_line() }
  }
}

test "a Console handler implements eprint" {
  with tagged() {
    Console.print("a")
    Console.eprint("b")
  }
  expect_output(["out: a", "err: b"])
}

test "log fields render as compact JSON" {
  Log.event(Level.Info, "search", [("hits", Json.Number(3.0)), ("id", Json.String("x"))])
  expect_output(["Info search hits=3 id=\"x\""])
}
```

### Results, files, generators and schemas

`Result.ok`/`err` turn one side into an `Option`. `Fs.read_up_to(path, limit)` fails
`FsError` past `limit` bytes. `Fs.memory_tree` is `Fs.memory` with directories
(`MemoryEntry.Directory`, `MemoryEntry.Contents(bytes)`). `Gen.flat_map` draws a value
from another. `Json.schema` (and a `Tool`'s schema) states a refinement's length and range
bounds as `maxLength`/`minLength`, `maxItems`/`minItems` and `maximum`/`minimum`; every
`where` is still checked on decode.

```sakura test id=since-data
import std/fs.{Fs, MemoryEntry}
import std/gen
import std/json.{Json}
import std/path.{Path}

type Name = String where String.len(it) >= 1 && String.len(it) <= 20

test "Result.ok and Result.err pick one side" {
  let r: Result<Int, String> = Err("bad")
  expect_eq(r.ok(), None)
  expect_eq(r.err(), Some("bad"))
}

test "a bounded read in a memory tree" {
  let tree = [
    (Path.of("out"), MemoryEntry.Directory),
    (Path.of("in/a.txt"), MemoryEntry.Contents(String.to_bytes("hello"))),
  ]
  with Fs.memory_tree(tree) {
    expect_eq(try { Fs.read_up_to(Path.of("in/a.txt"), 1024) }, Ok(String.to_bytes("hello")))
    expect(Result.is_err(try { Fs.read_up_to(Path.of("in/a.txt"), 4) }))
    expect(Result.is_ok(try { Fs.write(Path.of("out/b.txt"), String.to_bytes("x")) }))
  }
}

test "Gen.flat_map draws a value that depends on another" {
  let g = gen.flat_map(gen.list(gen.int(0, 9), 5), fn(xs) {
    gen.map(gen.int(0, Int.max(List.len(xs), 1) - 1), fn(i) { (xs, i) })
  })
  let s = with Random.seeded(7) { g.sample(4) }
  expect(s.1 < Int.max(List.len(s.0), 1))
}

test "a refinement's length bound reaches the schema" {
  let n: Option<Name> = None
  expect(String.contains(Json.encode(Json.schema(n)), "\"maxLength\":20"))
}
```

### Channels and stream buffering

`std/channel`'s `with_channel(capacity, body)` gives `body` a bounded `Sender` and
`Receiver`; both are resources (`V6003` if they escape). `Source.buffer` pulls ahead of its
consumer; `Source.tee` reads one source twice, at most `max_lag` items apart.

```sakura test id=since-conc
import std/channel
import std/channel.{Receiver, Sender}
import std/stream.{Source}

fn drain(rx: Receiver<Int>) -> Int ! {Task} {
  var n = 0
  var more = true
  while more {
    match rx.recv() {
      Some(x) => { n = n + x },
      None => { more = false },
    }
  }
  n
}

test "a bounded channel between two tasks" {
  let sums = with Task.deterministic(1) {
    channel.with_channel(2, fn(tx: Sender<Int>, rx: Receiver<Int>) {
      Task.all([
        fn() {
          for x in [1, 2, 3] { let _ = tx.send(x) }
          tx.close()
          0
        },
        fn() { drain(rx) },
      ])
    })
  }
  expect_eq(sums, [0, 6])
}

test "tee reads one source twice, at most 2 items apart" {
  let src: Source<Int, {}> = Source.from_list([1, 2, 3])
  let sums = with Task.deterministic(1) {
    src.tee(2, fn(a, b) {
      Task.all([
        fn() { a.fold(0, fn(s, x) { s + x }) },
        fn() { b.fold(0, fn(s, x) { s + x * 10 }) },
      ])
    })
  }
  expect_eq(sums, [6, 60])
}

test "buffer pulls ahead of its consumer" {
  let src: Source<Int, {}> = Source.from_list([1, 2, 3])
  let got = with Task.deterministic(1) { src.buffer(2, fn(s) { s.fold(0, fn(n, x) { n + x }) }) }
  expect_eq(got, 6)
}
```

### Workers (experimental)

`std/worker` is outside the 1.0 contract and may change in any release. An `@worker` entry
is `fn(Inbox<I>, Outbox<O>) -> Unit` (else `V1013`). `Worker.spawn(entry, grants, body)`
needs `grants` (`Grants.none()` or `Grants.of(Permissions { … })`) within the parent's
`[permissions]` and covering the entry's effects, else `Err(WorkerError(GrantExceeded))`.
Test with `Worker.inline()`.

```sakura test id=since-worker
import std/worker.{Grants, Inbox, Message, Outbox, Permissions, Worker}

@worker
fn double(inbox: Inbox<Int>, outbox: Outbox<Int>) -> Unit ! {Worker} {
  match Worker.recv(inbox) {
    Message(n) => { let _ = Worker.send(outbox, n * 2) },
    _ => {},
  }
}

test "a worker answers through its codec" {
  with Task.deterministic(1) {
    with Worker.inline() {
      let got = Worker.spawn(double, Grants.none(), fn(w) {
        let _ = Worker.send(w, 21)
        Worker.recv(w)
      })
      expect_eq("{got}", "Ok(Message(42))")
      let wide = Grants.of(Permissions {
        fs_read: [],
        fs_write: [],
        net: ["a.example:443"],
        env: [],
      })
      expect(Result.is_err(Worker.spawn(double, wide, fn(_w) { () })))
    }
  }
}
```

### Embedding from Node

A `pub fn` of the root module (not `main`, not `@worker`, not generic, schema-typed, row of
`Fail` errors and std effects with `host()`) is an entry. Node calls it with `callEntry`:
`sakura_wasm_host.js`'s `callEntry(host, name, args)` on WASM, `__entries__.js`'s
`callEntry(name, args)` on JS. `Untrusted<T>` may be a whole parameter or the result: pass
the plain value; the entry receives it as `Untrusted<T>`, and the host checks it against
`T`'s schema first. `Secret`, functions and `Untrusted` fields make a `pub fn` no entry.

```sakura check id=since-entries
pub type Parcel = { weight_g: Int }

pub fn weigh(input: Untrusted<Parcel>) -> Int {
  match Untrusted.check(input, "a positive weight", fn(p) { p.weight_g > 0 }) {
    Ok(p) => p.weight_g,
    Err(_) => 0,
  }
}
```

```js
const host = await new Host().instantiate(readFileSync("out/main.wasm")); // after loadTypes()
const o = await callEntry(host, "weigh", [new (rt.typeClass("pkg::main::Parcel"))(700)]);
// { kind: "ok", value: 700 }; a wrong value throws a HostFault before the call
```

Set the full permissions table below before the first call.

### Permissions table for embedders

A process that sets `SAKURA_PERMISSIONS` itself passes the full table; a key you leave out
is denied (`{}` grants nothing), and an unset variable means no host limits:

```json
{"fs": {"read": [], "write": []}, "net": [], "env": []}
```

## Decode JSON into a refined record

Decode an order once and let its field refinements reject invalid external data.

`Json.decode` infers `Order` from the return annotation and checks both the record
shape and the predicates on `item` and `quantity`. Its `Result` keeps malformed
JSON, missing fields and invalid quantities recoverable; `main` handles both
branches and reports the decoding path. Use `from` only for trusted values where a
failed predicate should be a defect. No permissions are needed.

Running `main` prints `2 x tea`; the repository's check runs it and both tests. The tests cover a valid
record, invalid JSON, an empty name, missing quantity and both out-of-range bounds.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/json_refined)

```sakura test id=cookbook-json_refined project=json_refined
import std/json.{DecodeError}

type Quantity = Int where it >= 1 && it <= 100
type Order = { item: String where String.len(it) > 0, quantity: Quantity }

fn read_order(text: String) -> Result<Order, DecodeError> { Json.decode(text) }

pub fn main() -> Unit ! {Console} {
  match read_order("\{\"item\":\"tea\",\"quantity\":2\}") {
    Ok(order) => Console.print("{order.quantity} x {order.item}"),
    Err(err) => Console.print("invalid order at {err.path}: {err.message}"),
  }
}

test "JSON decoding validates the record fields" {
  expect_eq(
    read_order("\{\"item\":\"tea\",\"quantity\":2\}"),
    Ok(Order { item: "tea", quantity: 2 }),
  )
}

test "malformed JSON and invalid fields are recoverable" {
  expect(Result.is_err(read_order("not json")))
  expect(Result.is_err(read_order("\{\"item\":\"tea\",\"quantity\":0\}")))
  expect(Result.is_err(read_order("\{\"item\":\"tea\",\"quantity\":101\}")))
  expect(Result.is_err(read_order("\{\"item\":\"\",\"quantity\":1\}")))
  expect(Result.is_err(read_order("\{\"item\":\"tea\"\}")))
}
```

## Read a file from a CLI

Decode command-line flags into a record and count a selected file's bytes.

`Cli.parse` infers `Args` from the binding. `Path` validates the relative path;
`Fs.rooted(Dir.subdir(...))` narrows access to `data` before reading. The manifest
permits reads only below `./data`. Counting bytes avoids treating file contents as
trusted instructions or decoding them unnecessarily. This small recipe reads the
whole file; use `Fs.with_file` and bounded `Fs.read_chunk` for large inputs.

`CliError` and `FsError` propagate to the CLI's failure reporter. Tests replace
arguments and files with `Cli.of` and `Fs.memory`, checking success, missing flags
and a missing file. The repository's check also runs `sakura run -- --input note.txt` against
the committed data file and expects `4 bytes`.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/cli_files)

```sakura test id=cookbook-cli_files project=cli_files
import std/cli.{Cli, CliError}
import std/fs.{Dir, Fs, FsError}
import std/path.{Path}

type Args = { input: Path }

fn byte_count() -> Int ! {Cli, Fs, Fail<CliError | FsError>} {
  let args: Args = Cli.parse(Cli.args())
  with Fs.rooted(Dir.subdir(Fs.root(), "data")) { Bytes.len(Fs.read(args.input)) }
}

pub fn main() -> Unit ! {Cli, Console, Fs, Fail<CliError | FsError>} {
  Console.print("{byte_count()} bytes")
}

test "CLI arguments select a file inside data" {
  with Cli.of(["--input", "note.txt"]),
      Fs.memory([(Path.of("data/note.txt"), String.to_bytes("tea\n"))]) {
    expect_eq(byte_count(), 4)
  }
}

test "missing arguments fail before reading" {
  with Cli.of([]), Fs.memory([]) {
    expect_fails_with(fn() { byte_count() }, fn(e) {
      match e {
        CliError { .. } => true,
        _ => false,
      }
    })
  }
}

test "a missing file remains FsError" {
  with Cli.of(["--input", "missing.txt"]),

    expect_fails_with(fn() { byte_count() }, fn(e) {
      match e {
        FsError { .. } => true,
        _ => false,
      }
    })
  }
}
```

## Retry HTTP with an offline cassette

Retry a safe GET after a rate limit, with a finite attempt count and virtual time in tests.

`fetch` declares HTTP, clock and random effects. Its policy retries only
`RateLimited`, at most three attempts, with exponential backoff and a one-second
retry deadline. Jitter is disabled for this example. It uses the policy's delays;
it does not interpret `retry_after`. The deadline bounds retry scheduling, not the
duration of an individual request. `HttpError` propagates immediately. Other HTTP
statuses remain responses for the caller to inspect.

The cassette returns 429 then 200 for the identical request. `Http.recording` is
wrapped by `Http.scripted([])`, so an exchange cannot fall through to the network,
even in recording mode. `Clock.virtual` advances without sleeping. Tests check
success after 100 ms, exhaustion after 300 ms, and immediate transport failure.
Only the tests run; the manifest grants no network or environment access.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/http_retry)

```sakura test id=cookbook-http_retry project=http_retry
import std/duration.{Duration}
import std/fs.{Fs}
import std/http.{Any, Http, RateLimited}
import std/path.{Path}
import std/response.{HttpError, Response, Status}
import std/retry
import std/retry.{Policy}

fn fetch() -> Response ! {Clock, Http, Random, Fail<HttpError | RateLimited>} {
  let policy: Policy<HttpError | RateLimited> = Policy {
    ..retry.policy(
      fn(err: HttpError | RateLimited) {
        match err {
          RateLimited { .. } => true,
          HttpError { .. } => false,
        }
      },
      3,
    ),
    jitter: false,
    deadline: Some(Duration.seconds(1)),
  }
  retry.retry(policy, fn() { Http.get(url"https://recipes.invalid/status") })
}

test "429 then success replays with a virtual backoff" {
  with Fs.rooted(Test.fixtures()),
      Http.scripted([]),
      Http.recording(Path.of("status.jsonl")),
      Clock.virtual() {
    let response = fetch()
    expect_eq(response.status, Status.from(200))
    expect_eq(Response.bytes(response, 64), String.to_bytes("ready"))
    expect_eq(Clock.monotonic(), Duration.millis(100))
  }
}

test "three rejected attempts preserve RateLimited" {
  with Http.scripted([(Any, Response.status(429, "busy"))]), Clock.virtual() {
    expect_fails_with(fn() { fetch() }, fn(e) {
      match e {
        RateLimited { .. } => true,
        _ => false,
      }
    })
    expect_eq(Clock.monotonic(), Duration.millis(300))
  }
}

test "a missing exchange does not reach a host or retry" {
  with Http.scripted([]), Clock.virtual() {
    expect_fails_with(fn() { fetch() }, fn(e) {
      match e {
        HttpError { .. } => true,
        _ => false,
      }
    })
    expect_eq(Clock.monotonic(), Duration.millis(0))
  }
}
```

## Query SQLite with bound parameters

Keep SQL text literal and interpolate values as parameters, then decode typed rows.

`find_notes` returns `List<Note>`, which determines the row schema for `Sql.query`.
Each `sql"…"` interpolation becomes a bound parameter; neither string concatenation
nor a trust bypass is needed. `SqlError` propagates from the database operations.

Tests install `Sql.memory`, a real fresh in-memory SQLite database, so no filesystem
permission or persistent database is needed. One test proves SQL-looking input
matches only its literal value. Another runs a transaction that writes and then
fails on an absent table, checks `SqlError`, and proves the first write rolled back.
Only the tests run. For a persistent database, query `sakura doc std::sql::sqlite`
and supply an appropriately confined filesystem handler and manifest permissions.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/sqlite_query)

### Source and tests

`src/main.sak` includes all required imports and tests.

```sakura test id=cookbook-sqlite_query project=sqlite_query
import std/sql.{Sql, SqlError}

type Note = { id: Int, title: String }

fn create_notes() -> Unit ! {Sql, Fail<SqlError>} {
  Sql.migrate([sql"create table notes (id integer primary key, title text not null)"])
}

fn add_note(title: String) -> Unit ! {Sql, Fail<SqlError>} {
  let _ = Sql.execute(sql"insert into notes (title) values ({title})")
}

fn find_notes(title: String) -> List<Note> ! {Sql, Fail<SqlError>} {
  Sql.query(sql"select id, title from notes where title = {title} order by id")
}

test "SQLite binds interpolated values, including SQL-looking text" {
  with Sql.memory() {
    create_notes()
    add_note("tea")
    let literal = "x' OR 1=1 --"
    expect_eq(find_notes(literal), [])
    add_note(literal)
    expect_eq(find_notes(literal), [Note { id: 2, title: literal }])
    expect_eq(find_notes("tea"), [Note { id: 1, title: "tea" }])
  }
}

test "a failing transaction rolls back earlier writes" {
  with Sql.memory() {
    create_notes()
    expect_fails_with(
      fn() {
        Sql.transaction(fn() {
          add_note("rolled back")
          let _ = Sql.execute(sql"insert into absent_table (title) values ({"bad"})")
        })
      },
      fn(e) {
```

## Test a router endpoint directly

Call the router as a function to test dispatch, request validation and response handling.

`Request.json` validates a refined name and caps the body at 256 bytes. The handler
maps `BadRequest` to a generic 400 response. `Router.handle` dispatches by method
and path, producing 404 or 405 when appropriate. There is no listener, socket,
`Serve` handler or permission to configure. Route patterns are `std/urlpattern`
patterns: `:name` matches one segment, and `/docs/**` matches any number of them,
which the handler reads as `Request.param(req, "0")`.

The tests call the actual router, not just the endpoint function. They assert the
successful response body, rejection of malformed JSON, an invalid refinement and
an oversized body, plus missing-route and wrong-method statuses. Only the tests run,
and no server is started.

## Bound an agent loop and its budget

Set both a turn limit and a spending limit, and test rejection before an unaffordable call.

`Agent.run` permits at most `max_steps` model turns and offers no tools on the last
turn. The tests verify that a model still requesting a tool then fails with
`InvalidOutput`. `BudgetExceeded`, other `LlmError` variants and `ToolError` propagate
in the declared failure union.

For finite accounting, put `Budget.limits` outside `Llm.anthropic` and replay HTTP
under `Http.recording` with an empty scripted fallback. Do not substitute
`Llm.replay` or `Llm.recording` here: those helpers install `Budget.unlimited`
internally. The placeholder `Secret` is not an API key, and no host HTTP handler or
network permission is installed.

The cassette's two turns report synthetic usage of 140 tokens each. The provider
reserves an estimate, `ceil(bytes of the request body / 4) + max_tokens` tokens at the
model's price, and settles that usage; the agent also holds a temporary
one-call reservation while a turn is in progress. Consequently the two-call run
needs a call limit of three for its overlapping reservations. A limit of two
rejects the second provider call. The tests exercise both cases, a token limit that
rejects before any scripted response is consumed, and the final-turn rule. These
are local accounting tests, not measured provider prices or a hard billing guarantee.
Only the tests run; no key, paid call or live service is involved.

## Update list indices with List.set

Reassign the new list returned by `List.set` while preserving earlier versions.

Collections have value semantics. `List.set(values, index, value)` returns a new
list; ignoring the result leaves `values` unchanged. The loop computes the length
once, handles empty input, then uses the half-open range `0..n`. Every read and
write is in bounds because replacement preserves length. An external index needs
both the nonnegative and upper-bound checks, as `replace_if_present` demonstrates.

The tests check changed values, the unchanged original list, empty and singleton
inputs, and external indices below zero, at the length and inside the list.
The repository's check also runs `main` and expects `[3, 0, 7, 0]`. No effects other than its
console output, permissions or slice/concat reconstruction are needed.

```sakura test id=cookbook-indexed_update project=indexed_update
fn replace_negatives(values: List<Int>) -> List<Int> {
  var updated = values
  let n = List.len(updated)
  if n == 0 { return updated }
  for i in 0..n {
    let value = List.get(updated, i).expect("i is inside the half-open range")
    if value < 0 { updated = List.set(updated, i, 0) }
  }
  updated
}

pub fn main() -> Unit ! {Console} { Console.print("{replace_negatives([3, -2, 7, -1])}") }

  let original = [3, -2, 7, -1]

  expect_eq(original, [3, -2, 7, -1])
}

  expect_eq(replace_negatives([]), [])
  expect_eq(replace_negatives([-1]), [0])
  expect_eq(replace_negatives([0, 4]), [0, 4])
}

fn replace_if_present(values: List<Int>, index: Int, value: Int) -> List<Int> {
  if index >= 0 && index < List.len(values) { List.set(values, index, value) } else { values }
}

  expect_eq(replace_if_present([7], -1, 9), [7])

  expect_eq(replace_if_present([], 0, 9), [])
```

## Build a URL with Url.parse and SearchParams

Parse a base URL, set its path and query parameters, and resolve links against it.

`Url.parse` is the WHATWG URL parser behind the web's `new URL(s)`: it lowercases the
scheme and host, drops a default port, resolves `.` and `..` segments and percent-encodes
what each component cannot hold, returning `UrlParts` or a `UrlError` with its reason.
Each `with_*` function returns a new value, so the base is never changed. `Url.search`
reads the query as `SearchParams`, an ordered multimap whose `set` replaces the first pair
of a name and keeps the rest of the query; `with_search` writes it back, encoding a space as
`+` and `&`, `=` or `#` in a value as `%26`, `%3D` and `%23`. `to_url` gives the `Url` that
`Request.of` takes. `Url.resolve` is `new URL(link, base)`, the step that turns a redirect's
`Location` header or a relative `next` link into an absolute URL.

The tests check that other parameters survive, that query text cannot add a parameter, that
relative, scheme-relative and absolute links resolve, and that a path-only `Url` (valid for
`Request.url`, but not absolute) and a non-ASCII host fail with `Relative` and `Idna`. No
effects or permissions are needed: a URL value grants nothing; `net` is checked when a
request is sent.

```sakura test id=cookbook-url_build project=url_build
/// The search endpoint under `base`'s origin, with `query` and `page` set and the base's other
/// parameters kept.
fn search_url(base: Url, query: String, page: Int) -> Url ! {Fail<UrlError>} {
  let parts = Url.parse(base)?
  let params = Url.search(parts).set("q", query).set("page", Int.to_string(page))
  parts.with_path("/v1/search")?.with_search(params).with_fragment(None).to_url()
}

/// A link from a response (a `Location` header, a `next` link) resolved against the URL that
/// was fetched.
fn follow(current: Url, link: String) -> Url ! {Fail<UrlError>} {
  Url.resolve(Url.parse(current)?, link)?.to_url()
}

pub fn main() -> Unit ! {Console, Fail<UrlError>} {
  let base = url"https://api.example.test/v0/items?key=k1&q=old#top"
  let first = search_url(base, "rust & sakura", 2)
  Console.print(first)
  Console.print(follow(first, "?q=next&page=3"))
  Console.print(follow(first, "../v2/items"))
}

}
```

## Upload a file as multipart form data

Build a `multipart/form-data` body with `Form`, send it, and parse it back within limits.

`Form` is the web's `FormData` as a value: an ordered list of fields, each `Text` or a
`File` holding a `FileData` (the web's `File`: a `Blob` of bytes and a media type, a name and
a time). `Form.encode_multipart` writes HTML's form-submission layout, and `Form.boundary()`
draws a fresh boundary from `Random`, so tests run under `Random.seeded` and get the same
bytes every time. The request's `content-type` names the boundary. The receiving side calls
`Form.parse_multipart` with a required `FormLimits`: the part count, the whole body and each
part are bounded, and a body over a bound, or one with the wrong content type, is a typed
`FormError` the handler turns into `400`. A file's name is data, never a path that is opened.

The request body is a `Payload`, here `Bytes`, so a file may hold any bytes. The tests send
a CSV upload through `Http.scripted`, replay a binary PNG upload and its binary answer from a
cassette (`Http.recording` stores a body that is not UTF-8 as Base64), route an upload request
through the receiving endpoint with `Router.handle`, and check the limit and content-type
refusals. No permissions are needed.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/form_upload)

```sakura test id=cookbook-form_upload project=form_upload
import std/form.{Form, FormError, FormLimits, Part}
import std/fs.{Fs}
import std/http.{Http, Matcher}
import std/path.{Path}
import std/request.{BadRequest, Bytes, Post, Request, Text}
import std/response.{HttpError, Response, Status}
import std/router.{Router}
import std/url.{Url}

/// A file named `name` holding `bytes` of `media_type`.
fn file(name: String, bytes: Bytes, media_type: String) -> FileData {
  FileData { blob: Blob.of(bytes, media_type), name, last_modified: Instant.from_unix_millis(0) }
}

/// The upload as a `POST` of a `multipart/form-data` body with a fresh boundary. The body is
/// `Bytes`, so the file may be any bytes.
fn upload_request(target: Url, title: String, report: FileData) -> Request ! {Random} {
  let form = Form { entries: [("title", Part.Text(title)), ("report", Part.File(report))] }
  let boundary = Form.boundary()
  Request.of(Post, target)
    .with_header("content-type", "multipart/form-data; boundary={boundary}")
    .with_payload(Bytes(Form.encode_multipart(form, boundary)))
}

fn upload(target: Url, title: String, report: FileData) -> Status
  ! {Http, Random, Fail<HttpError>}
{ Http.send(upload_request(target, title, report)).status }

fn csv(text: String) -> FileData { file("report.csv", String.to_bytes(text), "text/csv") }

/// The receiving side: at most 4 parts, 64 KiB in all and 32 KiB per part.
fn receive(req: Request) -> Response {
  let limits = FormLimits { max_parts: 4, max_bytes: 65_536, max_field_bytes: 32_768 }
  let content_type = Request.header(req, "content-type").unwrap_or("")
  try {
    match Form.parse_multipart(Request.bytes(req, limits.max_bytes), content_type, limits) {
      Ok(form) => {
        let names = List.map(form.entries, fn(e) {
          match e.1 {
            Part.Text(v) => "{e.0}={v}",
            Part.File(f) => "{e.0}={f.name} ({f.blob.media_type}, {Blob.size(f.blob)} bytes)",
          }
        })
        Response.status(201, List.join(names, "; "))
      },
      Err(FormError { reason }) => Response.status(400, "bad form: {reason}"),
    }
  } catch {
    BadRequest { detail } => Response.status(400, detail),
  }
}
```

## Verify a signed webhook with HMAC

Check that a webhook delivery carries a valid HMAC-SHA-256 signature before acting on it.

A webhook provider signs each body with a secret it shares with you and sends the tag in a
header, here `X-Signature` as Base64 (Shopify's `X-Shopify-Hmac-Sha256` has this shape).
`webhook_key` imports the secret as a `CryptoKey` that may only `Verify`: the material stays
a `Secret`, so the key is never shown, logged or serialized, and `export_key` refuses it.
`key.verify(tag, body)` recomputes the HMAC and compares it in constant time, so the time a
check takes does not reveal how many leading bytes of a forged tag were right. A missing
header or one that is not Base64 is not authentic, and the endpoint answers 401 without
saying why.

The tests sign deliveries the way the provider does and check that the right secret is
accepted, that a changed body, another secret, a missing header and a malformed one are
rejected, and that the receiving key cannot sign. They run the router as a function, with no
server, and need no effects or permissions: `std/crypto` is pure. In an application the
secret comes from `Env.secret`, which needs an `env` entry in `[permissions]`.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/sign_webhook)

```sakura test id=cookbook-sign_webhook project=sign_webhook
import std/bytes.{Alphabet}
import std/crypto
import std/crypto.{Algorithm, CryptoKey, Digest, KeyError, KeyFormat, Usage}
import std/request.{BadRequest, Request, Text}
import std/response.{Response, Status}
import std/router.{Router}

/// The provider's signing secret as an HMAC-SHA-256 key that can only verify.
fn webhook_key(secret: Secret<String>) -> Result<CryptoKey, KeyError> {
  let material = Secret.map(secret, fn(s) { String.to_bytes(s) }, @trust("webhook signing key"))
  crypto.import_key(KeyFormat.Raw, Algorithm.Hmac(Digest.Sha256), [Usage.Verify], false, material)
}

/// Whether `x-signature` is the Base64 HMAC-SHA-256 of the body under `key`, compared in
/// constant time. A missing or malformed header is not authentic. The tag covers the body's
/// bytes as they arrived, read by `Request.bytes`; a body over 64 KiB is `BadRequest`.
fn authentic(key: CryptoKey, req: Request) -> Bool ! {Fail<BadRequest>} {
  let body = Request.bytes(req, 65_536)
  match Request.header(req, "x-signature").map(fn(s) { Bytes.from_base64(s, Alphabet.Standard) }) {
    Some(Ok(tag)) => key.verify(tag, body),
    _ => false,
  }
}

fn receive(key: CryptoKey, req: Request) -> Response {
  try {
    if authentic(key, req) {
      Response.status(200, "accepted")
    } else {
      Response.status(401, "bad signature")
    }
  } catch {
    BadRequest { detail } => Response.status(400, detail),
  }
}

fn app(key: CryptoKey) -> Router<{}> {
  Router.new().post("/webhook", fn(req) { receive(key, req) })
}

/// What the provider does: sign `body` with the shared secret and send the tag in a header.
fn delivery(secret: String, body: String) -> Request {
  let signer = crypto.import_key(
    KeyFormat.Raw,
    Algorithm.Hmac(Digest.Sha256),
    [Usage.Sign],
    false,
    Secret.of(String.to_bytes(secret)),
  )
  let tag = match signer {
    Ok(key) => Bytes.to_base64(crypto.hmac(key, String.to_bytes(body)), Alphabet.Standard, true),
    Err(_) => "",
  }
  Request { ..Request.post("/webhook", body), headers: [("X-Signature", tag)] }
}

fn status_of(req: Request) -> Status {
  match webhook_key(Secret.of("whsec_test")) {
    Ok(key) => Router.handle(app(key), req).status,
    Err(_) => Status.from(500),
  }
}

test "a delivery signed with the shared secret is accepted" {
  expect_eq(status_of(delivery("whsec_test", "\{\"event\":\"paid\"\}")), Status.from(200))
}

test "a changed body or another secret is rejected" {
  let signed = delivery("whsec_test", "\{\"event\":\"paid\"\}")
  expect_eq(status_of(signed.with_payload(Text("\{\"event\":\"refund\"\}"))), Status.from(401))
  expect_eq(status_of(delivery("whsec_other", "\{\"event\":\"paid\"\}")), Status.from(401))
}

test "a missing or malformed signature is rejected" {
  let signed = delivery("whsec_test", "ping")
  expect_eq(status_of(Request { ..signed, headers: [] }), Status.from(401))
  expect_eq(
    status_of(Request { ..signed, headers: [("x-signature", "not base64!")] }),
    Status.from(401),
  )
}

test "the receiving key can verify but not sign" {
  match webhook_key(Secret.of("whsec_test")) {
    Ok(key) => {
      expect(crypto.permits(key, Usage.Verify))
      expect(!crypto.permits(key, Usage.Sign))
    },
    Err(_) => expect(false),
  }
}
```

## Read a file line by line with a stream

Count the lines of a log file in fixed-size reads, with every bound stated.

`Fs.file_source(file, 4_096)` is a view over the open `File`: each pull reads up to 4 KiB.
`Encoding.decode_source` turns those bytes into text, holding a UTF-8 sequence that a read
split until the next chunk completes it, and `lines(1_024)` splits the text on LF wherever
the chunks break, dropping a CR before an LF. `fold` walks the lines once. Memory is bounded
by the chunk and the line limit, not the file: a line over 1,024 bytes fails
`StreamError(MaxLine)` instead of growing, and a malformed byte fails `EncodingError`.

A source is a value. `summarize_text` takes any `Source<String, e>`, so a test hands it a
pure source built with `Source.from_list`, which reads the same items every time it is
pulled. The file view advances the file and is valid only inside the `Fs.with_file`
callback: returning it from the callback is `V6003`. The tests use `Fs.memory`, so they
need no permissions.

A rotated log is often gzipped. `summarize_gz` puts `compress.decompress_source` between
the file and the decoder: the codec state lives only inside its callback, the compressed
bytes are read 4 KiB at a time, and `max_out` (64 MiB here) bounds what the file may expand
to, so a small file that inflates without end fails `CompressionError(OutputLimit)` instead
of filling memory. A cut-off file fails `Truncated` and bytes that are not gzip fail
`Malformed(offset)`.

```sakura test id=cookbook-stream_lines project=stream_lines
import std/compress.{CompressionError, Format, Truncated}
import std/encoding.{Encoding, EncodingError, Errors, Malformed}
import std/fs.{Fs, FsError, Read}
import std/path.{Path}
import std/stream.{MaxLine, Source, StreamError}

pub type Summary = { lines: Int, errors: Int, longest: Int }

/// Counts the lines of a UTF-8 log and those that start with `ERROR`, reading the file in
/// 4 KiB chunks. A line over 1,024 bytes fails `StreamError(MaxLine)`; a malformed byte fails
/// `EncodingError`.
pub fn summarize(path: Path) -> Summary ! {Fs, Fail<EncodingError | FsError | StreamError>} {
  Fs.with_file(path, Read, fn(file) {
    summarize_text(Encoding.decode_source(Fs.file_source(file, 4_096), Encoding.Utf8, Errors.Fatal))
  })
}

/// The same count over a gzipped log. The file may expand to at most 64 MiB; past that the
/// read fails `CompressionError(OutputLimit)`.
pub fn summarize_gz(path: Path) -> Summary
  ! {Fs, Fail<CompressionError | EncodingError | FsError | StreamError>}
{
  Fs.with_file(path, Read, fn(file) {
    compress.decompress_source(
      Fs.file_source(file, 4_096),
      Format.Gzip,
      67_108_864,
      fn(plain) { summarize_text(Encoding.decode_source(plain, Encoding.Utf8, Errors.Fatal)) },
    )
  })
}

fn count(s: Summary, line: String) -> Summary {
  Summary {
    lines: s.lines + 1,
    errors: s.errors + (if String.starts_with(line, "ERROR") { 1 } else { 0 }),
    longest: Int.max(s.longest, String.len(line)),
  }
}

/// The same count over any source of text: a pure source in a test, a view in `summarize`.
pub fn summarize_text<e>(text: Source<String, e>) -> Summary ! {Fail<StreamError> | e} {
  text.lines(1_024).fold(Summary { lines: 0, errors: 0, longest: 0 }, count)
}
```

## Subscribe to a WebSocket feed

Open a WebSocket, subscribe to a topic and collect its updates until the server closes.

`WebSocket.connect` opens the connection and runs the callback with the `Socket`; when the
callback returns, fails or is cancelled the connection is closed (1001 if it is still open), and
returning the socket from the callback is `V6003`. There are no event listeners: a message or
the close is a value `WebSocket.receive` returns, and `WebSocket.messages(sock)` is the same as a
source that ends at the close, so `filter`, `map` and `to_list(max)` read it with a stated
bound. `max_message` caps each message at 64 KiB in both directions; a larger one from the
server ends the connection with 1009.

The manifest grants `feed.example.com:443`, the port a `wss` URL uses by default; a `main` that
declares `WebSocket` with an empty `net` list exits 75 at startup. The tests run against
`WebSocket.scripted`: `Reply` answers the subscription, `Push` sends updates, `Close` ends the
feed, and a send the script does not expect fails with `SocketError(Failed(...))` instead of
waiting. No test opens a socket.

## Serve a WebSocket chat room

Upgrade a route to a WebSocket and pass each member's messages to the rest of the room.

The route is an ordinary `Serve` handler. `WebSocket.handshake(req)` checks the opening
handshake without touching the connection, so a request that is not one is answered 426 with
`sec-websocket-version: 13`. `WebSocket.accept(req, options, member)` then upgrades it and runs
`member` with the `Socket`: the same `send`, `receive` and `close` a client has, closed with
1001 when `member` returns, fails or is cancelled. It returns the 101, and the server discards
what the handler returns for a connection it upgraded. When no upgrade happened it fails
`SocketError(Accept(reason))`: a browser page from an origin other than `chat.example.com` is
answered 403, and anything else, such as the `SAKURA_MAX_SOCKETS` limit, 503 with
`retry-after`. `origins` starts empty, which refuses every browser, since a browser sends the
victim's cookies with the upgrade; a client that sends no `origin` is admitted, and
authentication stays the handler's.

A `Socket` cannot be kept in handler state (`V6003`), so the room is a topic:
`WebSocket.subscribe(sock, "room")`, and `WebSocket.publish("room", message, Some(sock))`
writes to every other member without waiting, passing over one that is not reading. The runtime
has no idle timer and sends no pings: `timeout` around `receive` closes a member that has been
silent for five minutes. `max_message` caps each message at 64 KiB in both directions.

The manifest grants the listener's address; `accept` opens nothing, so it needs no entry of
its own. The tests run `Serve.scripted` around `WebSocket.scripted`, which plays the member, and
print `Get /chat -> 101 ` for the upgrade. No test opens a socket.

```sakura test id=cookbook-websocket_server project=websocket_server
/// The chat route. A request that is not a WebSocket handshake is answered 426 with the version
/// the server speaks; a browser page from an origin other than the chat's own is 403; a server
/// at its socket limit is 503. An accepted member joins the `room` topic, and each text message
/// it sends goes to every other member. A member silent for five minutes is closed with 4000.
pub fn chat(req: Request) -> Response ! {Clock, Task, WebSocket} {
  match WebSocket.handshake(req) {
    Err(why) =>
      Response { ..Response.status(426, why), headers: [("sec-websocket-version", "13")] },
    Ok(_) => join(req),
  }
}

fn join(req: Request) -> Response ! {Clock, Task, WebSocket} {
  let options = Upgrade {
    ..WebSocket.upgrade(),
    origins: ["https://chat.example.com"],
    max_message: 65_536,
  }
  match try { WebSocket.accept(req, options, member) } {
    Ok(switched) => switched,
    Err(e) => match e.reason {
      Accept(why) if String.starts_with(why, "origin ") => Response.status(403, why),
      _ => Response { ..Response.status(503, "busy"), headers: [("retry-after", "1")] },
    },
  }
}

fn member(sock: Socket) -> Unit ! {Clock, Task, WebSocket, Fail<SocketError>} {
  WebSocket.subscribe(sock, "room")
  WebSocket.send(sock, Text("welcome"))
  var open = true
  while open {
    match try { timeout(Duration.seconds(300), fn() { WebSocket.receive(sock) }) } {
      Ok(Data(Text(s))) => { let _ = WebSocket.publish("room", Text(s), Some(sock)) },
      Ok(Data(Binary(_))) => {},
      Ok(Closed(_)) => { open = false },
      Err(_) => {
        WebSocket.close(sock, 4000, "idle")
        open = false
      },
    }
  }
}

pub fn router() -> Router<{Clock, Task, WebSocket}> { Router.new().get("/chat", chat) }

test "a member is welcomed, talks, and leaves at the close; the upgrade answers 101" {
  let script = [Reply(Text("welcome"), Text("hello room")), Close(1000, "bye")]
  with Serve.scripted([WebSocket.upgrade_request("/chat", [])]),
      WebSocket.scripted(script),
      Clock.virtual(),
      Task.deterministic(1) {
    expect_fail(
      fn() { Serve.listen(router(), Address.of("127.0.0.1", 8080)) },
      ServeError { reason: "no more requests" },
    )
  }
  expect_output(["Get /chat -> 101 "])
}

test "a plain GET is 426, a foreign browser origin 403" {
  let foreign = Request.with_header(
    WebSocket.upgrade_request("/chat", []),
    "origin",
    "https://evil.example",
  )
  let plain = Request.with_header(Request.of(Get, Url.from("/chat")), "host", "example.test")
  with Serve.scripted([plain, foreign]),
      WebSocket.scripted([]),
      Clock.virtual(),
      Task.deterministic(1) {
    let _ = try { Serve.listen(router(), Address.of("127.0.0.1", 8080)) }
  }
  expect_output([
    "Get /chat -> 426 upgrade does not name websocket",
    "Get /chat -> 403 origin https://evil.example is not accepted",
  ])
}
```

## Extract a typed record from model output

Ask a model for a refined record type and test the extraction offline, scripted and replayed.

An `@llm` function declares the record it returns; the adapter asks the model for that type's
JSON Schema and decodes the answer against the type, refinements included, so a wrong answer
is the typed failure `InvalidOutput`, never a crash. The first two tests script the model with
`Llm.scripted`, which takes the answer itself. The other two replay
`tests/fixtures/extract_ticket.jsonl`, a synthetic Messages API exchange, through
`Llm.replay` and through `Llm.recording`, whose test `sakura test --record` would fetch once.

`Llm.anthropic` always sends to `https://api.anthropic.com`, so the cassette's keys are the
same on every machine; for another endpoint pass it with `Llm.anthropic_at(base, key, model)`
(no process variable is read).

`main` calls a real model, so only the tests are run here. The fixture's bodies, IDs and
token counts were invented (see its README); this is not live-provider validation.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/llm_extract)

```sakura test id=cookbook-llm_extract project=llm_extract
// `main` calls a real model, so CI runs the offline tests only: two under
// `Llm.scripted`, one replaying `tests/fixtures/extract_ticket.jsonl` with `Llm.replay` and
// the recorded test through `Llm.recording` (a synthetic cassette, see
// `tests/fixtures/README.md`). Difference from the design text: `extract_ticket` declares
// `Budget` and the tests install `Budget.unlimited()`, and `Budget.limits` is installed
// outside `Llm.anthropic`, whose handler performs `Budget` (the first handler in a `with` list
// is the outermost).

import std/budget.{Budget, Limits}
import std/fs.{Fs}
import std/http.{Http}
import std/llm.{InvalidOutput, Llm, LlmError, Model}
import std/path.{Path}

type Priority = Low | Normal | High

type Ticket = {
  title: String where String.len(it) > 0 && String.len(it) <= 120,
  priority: Priority,
  evidence: List<String>,
}

@llm(system: "Extract a support ticket. Use only facts present in the message.")
fn extract_ticket(message: Untrusted<String>) -> Ticket ! {Budget, Llm, Fail<LlmError>}

pub fn main() -> Unit ! {Console, Env, Http, Fail<LlmError>} {
  let key = Env.secret("ANTHROPIC_API_KEY").expect("set ANTHROPIC_API_KEY")
  let limits = Limits { tokens: Some(20_000), usd: Some(0.50), calls: None }
  with Budget.limits(limits), Llm.anthropic(key, Model.of("claude-sonnet-5-5")) {
    let t = extract_ticket(Untrusted.of("Login page 500s since 9am, blocking all customers"))
    Console.print("{t.priority}: {t.title}")
  }
}

test "scripted model output is validated against Ticket" {
  with Llm.scripted([
        Json.encode(Ticket { title: "Login 500s", priority: High, evidence: ["since 9am"] }),
      ]),
      Budget.unlimited() {
    let t = extract_ticket(Untrusted.of("anything"))
    expect_eq(t.priority, High)
  }
}

test "invalid output is a typed failure, not a crash" {
  // `\{` is a literal brace; a bare `{` would start an interpolation.
  with Llm.scripted(["\{\"title\": \"\", \"priority\": \"Urgent\"\}"]), Budget.unlimited() {
    expect_fails_with(
      fn() { extract_ticket(Untrusted.of("x")) },
      fn(e) {
        match e {
          InvalidOutput { .. } => true,
          _ => false,
        }
      },
    )
  }
}

test "a recorded Messages API exchange replays offline" {
  with Fs.rooted(Test.fixtures()), Budget.unlimited(), Llm.replay(Path.of("extract_ticket.jsonl")) {
    let t = extract_ticket(Untrusted.of("Login page 500s since 9am, blocking all customers"))
    expect_eq(t.priority, High)
    expect(t.title == "Login page returns 500 errors")
    expect_eq(t.evidence, ["Login page 500s since 9am", "blocking all customers"])
  }
}

test "a recorded exchange replays offline; sakura test --record fetches it once" {
  // Unset outside `sakura test --record`; the placeholder is a `Secret` too, and secret headers
  // are never written to the cassette. Plain `sakura test` denies the network, so
  // `Http.host()` is installed but never reached: the exchange replays from the cassette.
  let key = Option.unwrap_or(Env.secret("ANTHROPIC_API_KEY"), Secret.of("replay"))
  with Http.host(),
      Fs.rooted(Test.fixtures()),
      Budget.unlimited(),
      Llm.recording(
        Path.of("extract_ticket.jsonl"),
        Llm.anthropic(key, Model.of("claude-sonnet-5-5")),
      ) {
    let t = extract_ticket(Untrusted.of("Login page 500s since 9am, blocking all customers"))
    expect_eq(t.priority, High)
  }
}
```

## Run an agent loop with a tool

Give a model a typed tool and test the whole loop offline against a recorded two-step run.

`Tool.of` turns a named `@tool` function into a tool whose arguments are decoded against its
parameter types; `Agent.run` lets the model call it and returns the final answer as a typed
record. The test replays `tests/fixtures/research.jsonl`, a synthetic two-step cassette (a recorded exchange: a
tool turn, then the answer), through `Llm.replay`, the Anthropic adapter over the cassette, with the knowledge base the tool searches
answered by `Http.scripted`, so it needs no key and no network.

`main` calls a real model, so only the test is run here. The fixture's bodies, IDs and
token counts were invented (see its README); this is not live-provider validation.

[Source project](https://github.com/icantcodefyi/sakuralang/tree/main/compiler/examples/agent_loop)

```sakura test id=cookbook-agent_loop project=agent_loop
// `main` calls a real model, so CI runs the offline test only: `research`
// replays `tests/fixtures/research.jsonl` (a synthetic two-step cassette, see
// `tests/fixtures/README.md`) through `Llm.anthropic`, with the knowledge base scripted; the
// scripted agent-loop tests are `tests/semantics/std_agent.sak`. Difference from the design text: `Prompt`
// comes from `std/prompt` and `HttpError`, `Response`, `Status` from `std/response` (one
// home module per type, see compiler/std/INDEX.md), and `Budget.limits` is installed outside
// `Llm.anthropic`, whose handler performs `Budget`.

import std/agent.{Agent}
import std/budget.{Budget, Limits}
import std/fs.{Fs}
import std/http.{Any, Http, RateLimited}
import std/json.{DecodeError}
import std/llm.{Llm, LlmError, Model, Request}
import std/path.{Path}
import std/prompt.{Prompt, PromptPart}
import std/response.{HttpError, Response, Status}
import std/tool.{Tool, ToolError}
import std/url.{Url}

type Answer = { summary: String, sources: List<Url> }

error SearchDown

@tool("Search the internal knowledge base; returns up to 5 snippets")
fn kb_search(query: String) -> List<String>
  ! {Http, Fail<DecodeError | HttpError | RateLimited | SearchDown>}
{
  let resp = Http.get(url"https://kb.internal/search?q={query}")
  if resp.status != Status.from(200) { fail SearchDown }
  let snippets: List<String> = Response.json(resp, 100_000)
  snippets
}

pub fn research(question: Untrusted<String>) -> Answer
  ! {Budget, Http, Llm, Fail<LlmError | ToolError>}
{
  let req: Request<Answer> = Llm.request(
    "Answer with cited sources only.",
    Prompt.of([PromptPart.Untrusted(question)]),
  )
  Agent.run(Agent {
    request: req,
    tools: [Tool.of(kb_search)],
    max_steps: 8,
    stop: fn(_partial) { false },
  })
}

pub fn main() -> Unit ! {Console, Env, Http, Fail<LlmError | ToolError>} {
  let key = Env.secret("ANTHROPIC_API_KEY").expect("set ANTHROPIC_API_KEY")
  let limits = Limits { tokens: Some(60_000), usd: Some(2.0), calls: Some(20) }
  with Budget.limits(limits), Llm.anthropic(key, Model.default()) {
    let a = research(Untrusted.of("What is our refund policy for annual plans?"))
    Console.print(a.summary)
  }
}

test "a recorded agent run replays offline" {
  let kb = Response.status(200, "[\"Annual plans are refundable within 30 days of purchase.\"]")
  with Fs.rooted(Test.fixtures()),
      Budget.unlimited(),
      Http.scripted([(Any, kb)]),
      Llm.replay(Path.of("research.jsonl")) {
    let a = research(Untrusted.of("What is our refund policy for annual plans?"))
    expect(a.summary == "Annual plans can be refunded within 30 days of purchase.")
    expect_eq(List.len(a.sources), 1)
  }
}
```
