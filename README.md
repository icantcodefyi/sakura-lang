# Vow

An agent-first programming language: typed effects and errors, Rust-like memory efficiency without a borrow checker, and verification built in, so code written by AI agents works by construction.

> The signature is the contract. Humans review signatures; the compiler checks the code keeps its vows.

- `research/` — background research on prior art
- `docs/` — language design
- `website/` — vow website and docs
